# updev v0.6.3

`updev v0.6.3` is a public preview maintenance release for the
macOS/Homebrew/mise provider-gate line.

## Highlights

- Keeps the `v0.6.2` supported preview scope unchanged while preparing the code
  base for the next provider expansion.
- Moves Homebrew and mise update command argv builders into provider packages,
  so command handlers keep report mutation, finding-to-target selection, and
  TTY routing instead of rebuilding provider command chains inline.
- Centralizes Homebrew trust command argv builders in `internal/brew`,
  including the local-metadata `brew trust --json=v1` diagnostic path.
- Moves VS Code installed-extension command execution, output parsing, and
  error normalization into `internal/vscode`.
- Moves live manual inventory cask and Mac App Store probes into
  `internal/manualinventory`, keeping command code focused on report rows and
  actions.
- Updates source-structure and roadmap documentation so the current provider
  boundaries and next cleanup guardrails stay explicit.

## Supported Scope

This patch keeps the same preview scope as `v0.6.2`: macOS/Homebrew/mise is the
supported daily update and inventory workflow. Linux and Windows binaries may be
published for early validation, but Linux/Windows providers remain
experimental.

## Upgrade Notes

No config change is required.

- Existing `v0.6.x` config, cache, reports, and security policy files remain
  compatible.
- This release is intentionally a provider-boundary maintenance patch, not a
  new provider-support release.
- The user-facing command surface is unchanged; the main benefit is safer
  follow-up provider work with less command-local branching.
