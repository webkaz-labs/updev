# updev v0.5.6

`updev v0.5.6` is a public preview UX patch for Japanese description
translation in `updev list`.

## Highlights

- Japanese TTY `updev` and `updev list` can refresh cached `updev list`
  descriptions through the optional Codex CLI.
- `[ui].description_translation` now controls description translation with
  `auto`, `manual`, or `off`.
- Missing Codex remains non-fatal. `updev` keeps running with English
  descriptions, and dependency diagnostics report Codex as an optional backend.
- `updev list --translate-now` and `--retranslate-all` still work for explicit
  cache refreshes when translation is enabled.

## Upgrade Notes

No config file is required. The built-in behavior is:

```toml
[ui]
description_translation = "auto"
```

Set `manual` to translate only on explicit `updev list --translate-now` or
`--retranslate-all`, or `off` to disable translation attempts.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

With mise:

```bash
mise use -g github:webkaz-labs/updev@v0.5.6
```
