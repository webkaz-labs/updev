# updev v0.7.3

`updev v0.7.3` is a public-preview maintenance patch for support-label visibility.
It keeps the macOS/Homebrew/mise preview contract unchanged and makes existing
support boundaries easier to inspect from the human TUI.

## Highlights

- Added a routed support-catalog TUI view reachable from `updev hub` and the
  list hub.
- Added surface and label filter rows to the support-catalog TUI, with the
  normal `/` query filter and expandable details.
- Shows non-default provider support labels (`experimental`, `compatibility`,
  `deferred`) in provider review rows while keeping `supported_preview`
  detail-only in dense lists.
- Shows dependency compatibility `support_label` values in
  `updev doctor dependencies` text output as well as JSON.

## Notes

- No provider support level is promoted in this release.
- No new support-label vocabulary is introduced.
- Provider command execution still stays outside the alternate-screen TUI, so
  Homebrew and mise logs remain visible during update runs.
