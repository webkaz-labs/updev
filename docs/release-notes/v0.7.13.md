# updev v0.7.13

`updev v0.7.13` completes the route-to-intent TTY review pass for the
macOS/Homebrew/mise public preview. It keeps provider execution and log
streaming behavior unchanged while making summary, list, and cached-report
navigation lands on the focused item whenever updev already knows the target.

Highlights:

- Update summary inventory drift rows now open provider-scoped attention
  inventory rows instead of the full provider inventory.
- Update outcome rows route by intent: updated/skipped rows open update logs,
  while held/review/security rows open the matching security evidence.
- `updev list` can consume cached update summary inventory routes and keep the
  user inside the routed inventory browser with provider/status/query filters.
- Redundant standalone inventory attention/detail choices are hidden from the
  primary update/list hubs; grouped installed/manual inventory and item-scoped
  row actions are the primary path.
- Auxiliary compact/detail list views remain available from the hub as advanced
  routes instead of competing with the main inventory workflow.
- Global mise desired tools are pinned to explicit versions except the supported
  `node = "lts"` shortcut.

Validation:

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `git diff --check`
- `chezmoi apply --dry-run`
- Version JSON reports `updev v0.7.13`.
- TUI route-to-intent tests cover update summary routes, update outcome
  security routes, provider/status inventory routes, list cached-report routes,
  and hidden redundant hub actions.
