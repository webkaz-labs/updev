# updev v0.7.18

`updev v0.7.18` is a strict safety evidence precision patch for the
macOS/Homebrew/mise public preview.

Highlights:

- Homebrew advisory evidence now records advisory source, match type, severity,
  affected versions, and affected source ranges in cached reports and expanded
  detail views.
- OSV and curated advisory matches distinguish exact candidate-version affected
  evidence from source-range matches and weaker advisory-related evidence. TUI
  wording avoids implying a confirmed vulnerability when the evidence only
  requires review.
- Strict safety gate failures now summarize noisy provider metadata failures,
  such as package-manager debug-log pointers, without using raw stderr as item
  names. Raw error text remains available in structured evidence.
- Japanese safety text puts the strongest fact first for advisory holds,
  including when the update candidate itself is listed as affected.
- Regression coverage includes OSV affected-version classification,
  source-range classification, advisory evidence propagation, and concise
  metadata-failure summaries.

Validation:

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `mise -C tools/updev run goreleaser-check`
- `mise -C tools/updev run goreleaser-snapshot`
- `mise -C tools/updev run test-e2e-smoke`
- `git diff --check`
- `chezmoi apply --dry-run`
- `updev apply brewfile --dry-run --format json`
- `updev apply brewfile --safe-only --dry-run`
- `updev list --status missing --plain --limit 20`
