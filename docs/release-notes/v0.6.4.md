# updev v0.6.4

`updev v0.6.4` is a public preview maintenance release for the
macOS/Homebrew/mise provider-gate line.

## Highlights

- Keeps the `v0.6.3` supported preview scope unchanged while continuing the
  architecture cleanup needed before broader provider expansion.
- Moves action badge presentation from `internal/reviewui` into
  `internal/textui`, so grouped dashboard/list/detail views share one
  implementation for compact badge priority, truncation, status-aware coloring,
  and Nerd Font markers.
- Keeps `reviewui` focused on reusable browser/detail behavior: row action
  routing, focus, scroll, Back/Home state, expansion, and confirmations.
- Updates release, roadmap, architecture, and source-structure docs so the next
  v0.6.x work stays current-state focused instead of carrying old release logs.

## Supported Scope

This patch keeps the same preview scope as `v0.6.3`: macOS/Homebrew/mise is the
supported daily update and inventory workflow. Linux and Windows binaries may be
published for early validation, but Linux/Windows providers remain
experimental.

## Upgrade Notes

No config change is required.

- Existing `v0.6.x` config, cache, reports, and security policy files remain
  compatible.
- This release is intentionally a text UI and architecture-boundary maintenance
  patch, not a new provider-support release.
- The user-facing command surface is unchanged. The visible behavior of compact
  action badges should stay the same, but the implementation now has one owner
  package and dedicated tests.
