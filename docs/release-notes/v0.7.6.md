# updev v0.7.6

`v0.7.6` is a public-preview hotfix for the `v0.7.5` scalability refactor
release. It does not expand provider support or change the release scope:
macOS/Homebrew/mise remains the supported preview path, while Linux/Windows
inventory evidence, agent enrichment, and external installer execution remain
experimental or deferred.

## Fixes

- Restores consistency between English and Japanese TUI help text for the
  support-catalog label filter. The Japanese detail now mentions that `/` opens
  free-text query filtering, matching the English instruction.

- `mise -C tools/updev run docs-check`
