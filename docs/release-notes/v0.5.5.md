# updev v0.5.5

`updev v0.5.5` is a public preview diagnostics and documentation hardening
release. It keeps the main update workflow stable while making mise release-age
posture, agent usage, and documentation source-of-truth checks explicit.

## Highlights

- Reports mise native `minimum_release_age` status, value, source, and command
  shape support in `updev doctor dependencies` and `updev check --dependencies`.
- Adds mise release-age evidence to `updev fix mise` so `mise latest <tool>`
  resolutions show whether they ran under an effective provider-native age
  policy.
- Adds canonical agent guidance in `docs/agent/USAGE.md` and a compact
  installable skill artifact in `docs/agent/SKILL.md`.
- Adds `mise run docs-check` for high-value documentation drift checks:
  release-note presence, README links, agent guidance files, release-note
  workflow expectations, and mise/CI validation parity.
- Defines a documentation source-of-truth ledger so README, release notes,
  generated release bodies, validation docs, and future embedded skill output
  do not drift into competing copies.

## Supported preview scope

- macOS with Homebrew and mise.
- Homebrew-driven package state, Brewfile-derived desired state, mise tool
  checks, inventory, security gates, read-only planning workflows, and
  documentation/agent guidance for this preview scope.

## Experimental scope

- Linux and Windows binaries remain early validation artifacts.
- Broad Linux/Windows provider behavior is not yet stable.
- `updev skill` and `updev help agent` are planned after the canonical
  `docs/agent/` files can be embedded without duplicating command text.

## Install or upgrade

Use the checksum-verifying installer:

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

Or install the exact release with mise's GitHub backend:

```bash
mise use -g github:webkaz-labs/updev@v0.5.5
```
