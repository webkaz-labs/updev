# updev v0.5.8

`updev v0.5.8` is a public preview performance, portability, and cached-report
polish patch for the macOS/Homebrew/mise update workflow.

## Highlights

- `updev`, `updev list`, and `updev last` keep the accepted dashboard/list/detail
  TTY model from v0.5.7 while reducing perceived startup and return-path
  latency.
- Homebrew and mise provider commands still run outside the alternate-screen
  TUI, so non-dry-run update logs remain visible before the post-update
  dashboard opens.
- `updev last --plain`, JSON output, and non-TTY fallback stay deterministic and
  read the intended cached report without recomputing review domains.
- Dry-run reports are kept separate from real update reports, so dogfood runs do
  not overwrite the latest real update cache.
- Cached update evidence is normalized for list/dashboard badges: duplicate
  Homebrew progress rows are suppressed, skipped trusted-tap warnings keep their
  item names, and symbolic updates such as `latest` remain compact.
- `updev list` starts with grouped installed inventory and can switch to the
  manual app list from the same browser without forcing the full hub first.
- Manual inventory defaults are more portable for public users: repository-local
  Markdown is no longer an implicit desired-state source, and structured/manual
  draft metadata stays reviewable before it becomes desired state.
- TTY release tests now cover the dry-run cache name used by the current report
  contract.

## Supported Scope

This preview release is supported for the macOS/Homebrew/mise daily update and
inventory workflow. Linux and Windows binaries are published by the release
workflow for early validation, but Linux/Windows providers remain experimental.

## Experimental Scope

Manual/vendor app inventory, backend convergence suggestions, description
translation, agent-assisted manual metadata enrichment, and security policy
writes are preview features. They are designed to be explicit, reviewable, and
reversible, but they are not a stable v1 contract yet.

## Upgrade Notes

No config change is required.

- `updev` keeps the update-first workflow and opens the dashboard on TTY after
  provider logs finish.
- `updev list` opens installed inventory first; use `Tab` to switch to manual
  apps or `updev hub` for the full selector menu.
- `updev last` reopens cached report views. `--plain` and `--format json` remain
  deterministic agent/script output.
- Structured manual sources remain opt-in unless configured. Generated draft
  metadata must be accepted before it becomes desired state.
- Safe write actions still ask for confirmation before changing local policy,
  inventory overrides, mise config, or Brewfile ownership.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

With mise:

```bash
mise use -g github:webkaz-labs/updev@v0.5.8
```
