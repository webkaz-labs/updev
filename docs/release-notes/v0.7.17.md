# updev v0.7.17

`updev v0.7.17` is a summary-first TTY routing patch for the
macOS/Homebrew/mise public preview. It keeps the v0.7.16 Brewfile hook/apply
bridge and focuses on reducing the number of steps needed to move from the
post-update summary into the review views people use most often.

Highlights:

- The `inventory ok/drift` summary heading now opens the installed inventory
  list directly instead of applying an attention-only filter. Provider drift
  rows still open provider-scoped attention rows, while provider ok rows open
  the provider inventory list.
- `updev` and `updev last` summary dashboards now support one-key jumps:
  `i` for installed inventory, `m` for manual app inventory, `b` for backend
  convergence, `s` for security review, and `u` for update logs.
- The summary shortcut help text is visible in the dashboard controls, while
  child table/detail screens keep their existing local keymaps such as Back,
  filter, mouse toggle, and Tab view switching.
- The Brewfile apply bridge remains item-scoped and safety-gated. Daily hooks
  stay warning-only, and `[chezmoi_hooks.brewfile].mode = "apply-safe"` remains
  documented as a future opt-in shape rather than a default mutation path.
- Public documentation now describes the new dashboard shortcuts without
  depending on private paths, local profile names, or repository-specific
  desired-state assumptions.
