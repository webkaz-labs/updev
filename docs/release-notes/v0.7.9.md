# updev v0.7.9

`v0.7.9` is the agent-friendly quality tooling patch after the v0.7.8 large
refactor. It does not expand provider support: macOS/Homebrew/mise remains the
supported preview path, while Linux/Windows provider support remains
experimental.

## Highlights

- Promotes the proven Go CLI quality-tooling subset into the shared
  `docs/go-cli/` standard.
- Keeps the normal local `check` path low-noise with formatting/import checks,
  bug-class Staticcheck, curated `golangci-lint v2`, ShellCheck, tests, vet,
  module verification, and build.
- Keeps slower vulnerability, supply-chain, and agent-code-quality checks in
  the release or scheduled `audit` path.
- Tracks deterministic agent-quality findings as non-blocking evidence unless a
  future release promotes a narrow low-noise finding class.
- Updates the shared Go CLI template project so new tools inherit the same
  `check` versus `audit` split.

## Validation

- `mise -C tools/updev run check`
- `mise -C tools/updev run audit`
- `mise -C tools/updev run docs-check`
- `mise -C docs/go-cli/template-project run check`
- `mise -C docs/go-cli/template-project run audit`
- `git diff --check`
- `chezmoi apply --dry-run`
