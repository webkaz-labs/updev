# updev v0.5.4

`updev v0.5.4` is a public preview polish release for macOS-first package and
developer-tool maintenance. It keeps the CLI behavior stable while making the
public installation path, release assets, and security posture easier to
understand.

## Highlights

- Adds a checksum-verifying shell installer for the common latest-release path.
- Keeps the mise GitHub backend install path documented for users who already
  manage global tools with mise.
- Clarifies that `config.toml` is optional when the default behavior is enough.
- Refocuses the README around update planning, inventory, safety gates, and
  supply-chain hold behavior.
- Adds a workflow visual and public docs cleanup for first-time users.
- Updates GitHub Actions release infrastructure to current action runtimes and
  artifact behavior.

## Supported preview scope

- macOS with Homebrew and mise.
- Homebrew-driven package state, Brewfile-derived desired state, mise tool
  checks, inventory, security gates, and read-only planning workflows.

## Experimental scope

- Linux and Windows binaries are published for early validation, but broad
  Linux/Windows provider behavior is not yet stable.
- Manual/vendor app inventory remains opt-in and review-oriented.

## Install or upgrade

Use the checksum-verifying installer:

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

Or install the exact release with mise's GitHub backend:

```bash
mise use -g github:webkaz-labs/updev@v0.5.4
```

## Validation

The release was prepared with the public preview gates:

- `go test ./...`
- `go vet ./...`
- `go build ./...`
- `go mod verify`
- `git diff --check`
- release asset checksum verification through `scripts/install.sh`
