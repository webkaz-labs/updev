# updev v0.7.20

`updev v0.7.20` is a package-authority and architecture-ownership update for
the macOS/Homebrew/mise public preview. The `v0.7.19` implementation baseline
was not tagged separately; users upgrade directly from `v0.7.18` to
`v0.7.20`.

## Highlights

- Added read-only mise v2026.8.2 bootstrap capability, active-source,
  package-parity, and package-executor reports.
- Connected safe missing-package application to item-scoped native Homebrew or
  mise executors without uninstalling extras or routing outdated packages
  through the apply bridge.
- Migrated the bounded `brew/formula/btop` desired-state pilot to mise while
  retaining native Homebrew execution on Intel macOS and explicit rollback
  evidence.
- Made backend convergence registry-first for supported formula and CLI-only
  cask candidates, with bounded architecture/checksum evidence and separate
  desired-state adoption/removal actions.
- Moved provider-neutral update report and strict command planning ownership to
  `internal/updatereport` and `internal/updateplan`, and consolidated inventory
  and package execution behind injected runner seams.
- Added representative outer command parsing coverage for update, list, last,
  and apply; removed unused forwarding helpers; and made Staticcheck `U1000`
  dead-code findings blocking.
- Reduced `reviewui` to its command-consumed API while preserving routed TTY
  focus, Back/Home, expanded-row visibility, and action-consumption behavior.
- Added pinned shell-use semantic journeys on Linux and Intel macOS, exact
  terminal snapshots on macOS, and executable validation-block checks.
- Kept daily Brewfile hooks warning-only. They never call `brew bundle`; native
  bootstrap remains an explicit first-machine or recovery path.
- Made `brewtmplcheck` resolve installed Homebrew identities through the
  batched updev authority contract, so mise-owned packages remain desired;
  resolution failures retain visible drift instead of hiding it.
- Hardened pinned Go analyzer caching and raised the supported Go 1.26 patch
  level. Staticcheck and golangci-lint validate their shared module caches and
  rebuild only corrupt analyzer caches with deterministic recovery fixtures.
- Split oversized CLI, data-model, and validation documents into stable indexes
  with one-level child domains. The docs gate rejects broken links and orphaned
  children while the release smoke remains executable from `VALIDATION.md`.
- Hardened the tag workflow so it reruns the reusable CI gate, rejects a
  version/tag mismatch, publishes GoReleaser archives and checksums, and attests
  the checksum manifest.

## Compatibility

- macOS with Homebrew and mise remains the supported preview.
- Linux and Windows binaries remain available with experimental provider
  behavior; this release does not promote those provider contracts.
- Existing text, JSON, cached-report, and TTY entrypoints remain compatible.
- The tmux PTY suite remains a compatibility gate until its remaining journeys
  are covered by the shell-use harness.

## Install Or Upgrade

- Latest installer: `curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh`
- Pinned installer: append `-s -- --version v0.7.20` to the installer command.
- mise: `mise use -g github:webkaz-labs/updev@v0.7.20`
- Existing users can rerun their chosen install method; no config migration is
  required.
