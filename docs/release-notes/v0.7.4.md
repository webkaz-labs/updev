# updev v0.7.4

`v0.7.4` is a public-preview foundation patch. It does not expand provider
support; macOS/Homebrew/mise remains the supported preview path, while
Linux/Windows inventory evidence, agent enrichment, and external installer
execution remain experimental or deferred.

## Highlights

- Extracted installed-list evidence projection into `internal/plan` so
  `internal/cmd` keeps route/action wiring instead of owning evidence matching
  and counting logic.
- Tightened evidence key matching for provider update/security rows:
  provider-prefix rows such as `cask demo-app` and version-delta rows such as
  `tool 1.0.0 -> 1.1.0` now project cleaner item identities.
- Added focused `plan` package tests for evidence key aliases, item evidence
  lookup, and duplicate count handling.
- Kept scanner and policy defaults unchanged. Optional scanners stay
  non-blocking for normal update flows, and policy cleanup diagnostics remain
  the current ergonomics foundation.

## Validation
