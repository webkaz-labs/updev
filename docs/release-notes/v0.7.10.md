# updev v0.7.10

`v0.7.10` is the provider evidence quality patch after the v0.7.9
quality-tooling release. It does not expand provider support:
macOS/Homebrew/mise remains the supported preview path, while Linux/Windows
provider support remains experimental.

## Highlights

- Adds richer Homebrew and mise security evidence to text details, cached report
  detail views, and TUI detail rows.
- Shows release age, release date, source, tap, repository, support URL,
  homepage/download hosts, published/updated timestamps, and safety-cache
  context where provider data is available.
- Keeps compact inventory rows readable while moving the expanded evidence into
  detail views.
- Improves Japanese localization for mise security evidence, including GitHub
  release/tag metadata unavailability and mise `minimum_release_age`
  remediation.
- Preserves strict-mode item-scoped allow/hold/review behavior and provider log
  streaming outside the alternate-screen TUI.

## Validation

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `git diff --check`
- `chezmoi apply --dry-run`
- Real-machine plain checks:
  - `updev last --plain --section security --details`
  - `updev list --plain --details --query wezterm`
  - `updev list --plain --details --query mole`
  - `updev --dry-run --plain --no-interactive`
