# updev v0.7.11

`v0.7.11` is the scanner hardening patch after the v0.7.10 provider evidence
detail release. It does not expand provider support:
macOS/Homebrew/mise remains the supported preview path, while Linux/Windows
provider support remains experimental.

## Highlights

- Adds structured scanner/native-audit unavailable and error evidence to JSON:
  `unavailable_reason` for unavailable checks and `error_kind` for failed
  checks.
- Distinguishes missing scanner binaries, unsupported targets, skipped-by-scope
  native audits, timeouts, rate limits, parse failures, report-unavailable
  conditions, and command errors.
- Shows the same scanner/native-audit classification in text output through the
  compact `issue` column.
- Keeps optional missing scanners from failing normal security scan status while
  still making coverage gaps visible.
- Carries native-audit issue context into security review prompts without
  generating unsafe policy commands for native-audit unavailable rows.
- Preserves provider log streaming outside the alternate-screen TUI and does
  not make Trivy, Grype, Syft, or Prowler default update gates.

## Validation

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `git diff --check`
- `chezmoi apply --dry-run`
