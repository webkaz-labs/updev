# updev v0.7.8

`v0.7.8` is the required large refactor after the v0.7.7 guardrail patch. It
does not expand provider support: macOS/Homebrew/mise remains the supported
preview path, while Linux/Windows inventory evidence, agent enrichment, and
external installer execution remain experimental or deferred.

## Highlights

- Reduces `internal/cmd` production files to 20 and command test files to 14,
  then tightens the source-structure check to enforce those budgets.
- Extracts updev config loading, TOML parsing, environment override handling,
  and config validation into `internal/updevconfig`.
- Extracts read-only sync report construction, drift classification, provider
  mismatch keys, and guidance construction into `internal/syncreport`.
- Consolidates update/list routed TUI adapters into their parent command
  adapters while keeping shared route state, pending actions, and focus
  restoration in `reviewui`.
- Consolidates mise bump and mise release-age safety adapters under the safety
  command adapter without changing provider log streaming or item-scoped gate
  behavior.
- Consolidates related command tests by behavior contract without deleting
  coverage, so future owner-specific tests have a clearer home.
