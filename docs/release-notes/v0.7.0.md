# updev v0.7.0

`updev v0.7.0` is a public-preview hardening release. It does not claim a
stable `v1.0.0` contract; it makes the preview contract easier to inspect and
dogfood before that decision.

## Highlights

- Adds `updev support` and `updev doctor support` as read-only support-level
  catalogs for providers, commands, report families, and inventory sources.
- Labels public surfaces as `supported_preview`, `experimental`,
  `compatibility`, or `deferred` so humans and agents can distinguish the
  macOS/Homebrew/mise preview path from Linux/Windows/agent-enrichment
  groundwork.
- Extends `updev doctor dependencies` compatibility ledger entries with
  `support_label`, making provider contract drift artifacts easier to interpret
  in local and CI review.
- Keeps Linux read-only scanners, Windows `winget export` evidence, and
  agent/manual enrichment experimental and default-off.
- Keeps `brewfile` as a compatibility surface rather than the main human
  workflow.

## Supported Scope

macOS/Homebrew/mise remains the supported preview path. Linux and Windows
binaries continue to be published for early testing, but Linux/Windows provider
support remains experimental. External/vendor installer execution, dynamic
provider plugins, and stable Linux/Windows update providers remain deferred.

## Upgrade Notes

No config migration is required.

- `updev version` now reports `updev v0.7.0`.
- `updev support --format json` exposes the support catalog for automation.
- `updev doctor support` prints the same catalog from the doctor namespace.
- `updev doctor dependencies --format json` and `--ledger <file>` now include
  `support_label` on compatibility ledger entries.
