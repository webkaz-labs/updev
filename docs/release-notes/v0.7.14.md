# updev v0.7.14

`updev v0.7.14` is the first polish patch after the route-to-intent completion
release. It keeps the macOS/Homebrew/mise public-preview scope and focuses on
reducing review friction without broadening provider support.

Highlights:

- Homebrew extra live inventory rows now explain likely drift causes such as
  direct `command brew`/full-path usage, another shell, `brew bundle`,
  vendor/app sidecar installs, or packages installed before wrapper adoption.
- Homebrew drift rows expose category-explicit Brewfile adoption actions from
  inventory details. The write path goes through the existing mutation boundary
  and does not guess the category.
- `updev hub` now behaves as a review-domain switcher instead of duplicating the
  full `updev list` filter menu. Installed inventory, manual apps, backend
  convergence, update evidence, security review, support catalog, and advanced
  compact/detail views remain reachable.
- `updev list` keeps provider/kind/category/status/query filtering focused on
  inventory browsing, while Back/Home can move to the domain switcher when the
  user wants another review surface.
- Routed write actions can refresh the current inventory/report context after a
  confirmed Homebrew adoption, so returning to the browser does not require a
  generic second selection.
- Bounded quality cleanup reduced local duplication around Homebrew drift
  explanation and action routing, with focused tests covering the new behavior.

Validation:

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `git diff --check`
- `chezmoi apply --dry-run`
- Version JSON reports `updev v0.7.14`.
- Homebrew drift tests cover detail explanations and category-explicit Brewfile
  adoption through the mutation boundary.
- Hub tests cover the review-domain switcher and preserve filter choices for
  internal routed menus.
