# updev v0.7.19

`updev v0.7.19` completes the first bounded mise-centered package authority
slice and hardens the full-TUI release gate.

## Highlights

- Added read-only mise v2026.8.2 bootstrap capability, active-source,
  package-parity, and package-executor reports.
- Connected safe missing-package application to item-scoped native Homebrew or
  mise package executors without uninstalling extras or updating outdated
  packages through the apply bridge.
- Migrated `brew/formula/btop` desired ownership to mise while preserving the
  Intel macOS native Homebrew executor and explicit rollback evidence.
- Made backend convergence registry-first for supported formula and CLI-only
  cask candidates, with bounded architecture/checksum evidence and separate
  desired-state adoption/removal actions.
- Kept daily Brewfile hooks warning-only and bootstrap explicitly separate from
  the normal safety gate.
- Made `brewtmplcheck` resolve installed Homebrew identities through the
  batched updev authority contract, so mise-owned packages such as the `btop`
  pilot remain desired without returning to the Brewfile. Resolution failure
  retains the original drift instead of hiding it.
- Hardened pinned Go quality-tool caching and raised the supported Go 1.26
  patch level used by release builds. Staticcheck and golangci-lint now verify
  their shared module caches and rebuild only a corrupt analyzer cache, with
  deterministic healthy/corrupt/symlink cache fixtures in the standard gate.
- Added project-pinned Microsoft shell-use semantic journeys, terminal
  snapshots, and resvg/ODiff visual baselines for the critical TUI states.
- Added an executable `VALIDATION.md` block gate that rejects comment-only or
  incomplete assertions.
- Reorganized the oversized CLI, data-model, and validation contracts into
  concise stable indexes with one-level child documents. The docs gate now
  rejects broken links and orphaned domain children while the release smoke
  remains executable from the stable validation index.

## Compatibility

- The supported preview remains macOS with Homebrew and mise.
- Existing text, JSON, cached-report, and TTY entrypoints remain compatible.
- The existing tmux PTY suite remains temporarily as a migration compatibility
  gate and will be removed only after shell-use parity is proven in CI and real
  terminals.
