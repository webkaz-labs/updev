# updev v0.6.0

`updev v0.6.0` is a public preview provider-gate release for the
macOS/Homebrew/mise update workflow.

## Highlights

- Adds an updev-owned mise release-age gate for GitHub-backed and selected
  registry-backed mise candidates, using the same `allow`, `hold`, `review`,
  and `block` vocabulary as Homebrew.
- Surfaces mise-native `minimum_release_age` evidence without depending on a
  global mise setting for updev's own decisions.
- Runs strict updates with scoped provider commands: safe mise candidates use
  `mise upgrade --minimum-release-age <Nd> <tool...>`, and safe Homebrew
  candidates use scoped `brew upgrade --greedy <name...>` while held rows remain
  visible.
- Shows pinned-version mise bump opportunities separately from ordinary updates,
  with manual, safe-batch, and auto modes that only apply reviewed safe
  candidates.
- Aligns Homebrew safety evidence with `brew upgrade --greedy`, including
  greedy-only cask candidates and local tap metadata fallback for Homebrew JSON
  probes.
- Improves manual/vendor evidence quality with source URLs, ownership
  confidence, provider-native metadata, and portable defaults that do not depend
  on this dotfiles repository.
- Keeps the v0.5.x routed TTY model: provider logs remain visible before the
  dashboard, and list/detail/security/backend/manual actions stay reachable from
  the same review flow.

## Supported Scope

This preview release is supported for the macOS/Homebrew/mise daily update and
inventory workflow. Linux and Windows binaries are published for early
validation, but Linux/Windows providers remain experimental.

## Experimental Scope

Manual/vendor app inventory, backend convergence suggestions, description
translation, agent-assisted manual metadata enrichment, security policy writes,
and pinned-version mise auto-bump mode are preview features. They are explicit,
reviewable, and reversible, but they are not a stable v1 contract yet.

## Upgrade Notes

No config change is required.

- `updev` uses strict security gates by default.
- updev enforces its own mise release-age threshold and does not require a
  global mise-native `minimum_release_age` setting.
- Set `[security.mise].min_release_age_days` or
  `UPDEV_MISE_MIN_RELEASE_AGE_DAYS` to tune the mise gate for one environment.
- Set `[security.homebrew].outdated_timeout_seconds` or
  `UPDEV_BREW_OUTDATED_TIMEOUT_SECONDS` when `brew outdated --json=v2 --greedy`
  needs a longer bounded probe on a local machine.
- Homebrew safety discovery always uses local tap metadata with
  `HOMEBREW_NO_INSTALL_FROM_API=1`, avoiding Homebrew 6 internal package JSON
  endpoint failures during strict gates.
- `updev doctor dependencies` reports Homebrew 6 tap trust drift for
  non-official Brewfile tap/formula/cask entries and security posture rows show
  preferred item-scoped `brew trust` commands. updev does not auto-trust taps.
- Set `[update.mise_bump].mode` or `UPDEV_MISE_BUMP_MODE` to control
  pinned-version bump behavior: `off`, `manual`, `safe`, or `auto`.
- `mise-bump` GitHub rate-limit failures are reported as held/review discovery
  gaps instead of failing the whole update.
- updev passes available GitHub credentials to mise subprocesses as
  `MISE_GITHUB_TOKEN` without recording the token in report command lines.
- Held/review rows remain visible in the dashboard, list, last-report, and
  security detail surfaces.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

With mise:

```bash
mise use -g github:webkaz-labs/updev@v0.6.0
```
