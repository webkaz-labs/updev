# updev v0.5.7

`updev v0.5.7` is a public preview dogfood UX foundation patch for interactive
update review.

## Highlights

- The post-`updev` dashboard and detail browser expose focused-row action hints
  before expansion, so reviewable rows show `a/1`, `2`, ... actions where safe
  actions exist.
- Manual app review, backend convergence, and security findings can be opened
  and expanded from the same TTY review flow. Safe actions ask for confirmation
  before changing local state.
- `updev list --interactive` opens the grouped installed inventory browser
  first. Back/Home from that browser opens the full selector menu so manual app
  rows, backend convergence, cached update/security evidence, and filters remain
  easy to reach.
- `updev hub` opens the full list view/filter selector menu directly for users
  who prefer the old all-menu entry point.
- Review-plan preparation now uses visible startup progress so `list`, `last`,
  and returns from backend/manual detail views do not look frozen while cached
  review actions are being prepared.
- `updev last` reopens the cached post-update hub on TTY without running
  provider updates again. `--section security`, `--section inventory`,
  `--section logs`, and related section flags choose a useful initial view;
  `--plain` keeps the same cached report in deterministic text output.
- Homebrew and other provider stdout/stderr keep meaningful newlines in expanded
  update/log details.
- Backend recommendations now distinguish applyable safe rewrites/removals from
  review-only candidates, including `mise/github` evidence that still needs
  asset, version-mapping, and ownership review before replacing a provider.

## Upgrade Notes

No config change is required. The new interactive paths are additive:

- `updev`, `updev list`, and `updev last` are the primary TTY entry points.
- `--plain` keeps `updev`, `updev list`, and `updev last` in deterministic
  text output for logs and agents.
- Safe write actions still ask for confirmation before changing local policy,
  inventory overrides, mise config, or Brewfile ownership.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/webkaz-labs/updev/main/scripts/install.sh | sh
```

With mise:

```bash
mise use -g github:webkaz-labs/updev@v0.5.7
```
