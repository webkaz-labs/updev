# updev v0.7.7

`v0.7.7` is a public-preview architecture hardening patch before the next
provider/scanner/policy feature slice. It does not expand provider support:
macOS/Homebrew/mise remains the supported preview path, while Linux/Windows
inventory evidence, agent enrichment, and external installer execution remain
experimental or deferred.

## Highlights

- Enforces `internal/cmd` production-file budget separately from command test
  files. Production command files are now capped at `<= 30`; the current count
  is 27.
- Tracks command test files as their own budget so broad regression tests remain
  visible without weakening the production command-sprawl guardrail.
- Updates source-structure documentation and checks so future provider evidence,
  scanner hardening, and policy ergonomics cannot silently grow production
  command logic.
- Keeps provider-native Homebrew/mise logs on the existing runner/update path;
  Bubble Tea foreground process execution remains reserved for future explicit
  TUI actions, not provider update/scan/audit execution.
