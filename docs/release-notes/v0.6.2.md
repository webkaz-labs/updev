# updev v0.6.2

`updev v0.6.2` is a public preview maintenance release for the `v0.6.0` /
`v0.6.1` macOS/Homebrew/mise provider-gate line.

## Highlights

- Completes the first P1 architecture cleanup slice after the public `v0.6.1`
  tag without changing the supported preview scope.
- Extracts backend recommendation planning into `internal/backend`, keeping
  provider evidence, preference policy, recommendation actions, and source
  evidence out of command-local branches.
- Centralizes reusable support code for root/config/cache path resolution,
  security gate reports, and update-safety cache storage.
- Moves manual inventory parsing, draft/override rendering, agent request
  construction, review models, and row classification into
  `internal/manualinventory`, keeping command files focused on CLI/TUI routing
  and write-flow wiring.
- Moves shared review actions, selectable summary browsing, compact age/filter
  formatting, inventory status/query helpers, security review filter summaries,
  and update-log summarization into their owner packages (`reviewui`, `textui`,
  `plan`, and `updatelog`) so command handlers keep shrinking without changing
  reports or TTY routes.
- Adds a direct-subprocess drift check so provider commands keep using the
  shared runner path unless they are documented exceptions.
- Makes Homebrew 6 non-official tap/package trust findings actionable from
  security detail views. Formula and cask rows can run confirmed item-scoped
  `brew trust --formula` / `brew trust --cask` actions; whole-tap trust remains
  a separate confirmation-only action and never runs automatically during
  update.
- Hardens the public export path so dotfiles-only documentation rows are
  removed from the split repository and exported Markdown local links are
  checked before release.

## Supported Scope

This patch keeps the same preview scope as `v0.6.0` and `v0.6.1`:
macOS/Homebrew/mise is the supported daily update and inventory workflow. Linux
and Windows binaries are still published for early validation, but Linux/Windows
providers remain experimental.

## Upgrade Notes

No config change is required.

- Existing `v0.6.x` config, cache, reports, and security policy files remain
  compatible.
- Homebrew trust actions are explicit write actions from security detail views;
  update itself still does not auto-trust taps or packages.
- Backend recommendation JSON/detail output includes source evidence where
  available, which can make review rows more explanatory without changing the
  provider ownership model.
