# updev v0.7.12

`updev v0.7.12` is a policy and routed-action ergonomics patch for the
macOS/Homebrew/mise public preview. It does not expand provider support or
scanner defaults; it makes the existing review surfaces easier to act on.

Highlights:

- Security policy reports now surface cleanup diagnostics for expired, invalid,
  duplicate, shadowed, broad, missing-reason, and missing-expiry rules.
- Policy maintenance flows keep explicit local intent: add, update, remove,
  renew, and cleanup are available from deterministic CLI/text/JSON surfaces
  without creating broad permanent allows by default.
- Update and security reports preserve policy decision metadata so text, JSON,
  and TUI detail views agree on the same reason codes.
- TUI row actions now behave as route-to-intent actions where possible. A row
  action carries its domain, target, intent, and origin so the next view opens
  the matching item detail directly instead of making the user choose the item a
  second time.
- Installed inventory item details now show compact evidence summaries instead
  of repeating long source/cache/download fields already available from the
  routed evidence views.
- `updev`, `updev last`, and `updev list` keep provider log streaming outside
  the alternate-screen TUI while improving focused detail navigation.
- List update-evidence actions can open the relevant item-scoped security or
  update detail view and return to the originating list context.
