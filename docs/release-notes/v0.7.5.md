# updev v0.7.5

`v0.7.5` is the scalability refactor completion patch for the `v0.7.x`
public preview. It does not expand provider support; macOS/Homebrew/mise
remains the supported preview path, while Linux/Windows inventory evidence,
agent enrichment, and external installer execution remain experimental or
deferred.

## Highlights

- Reduced `internal/cmd` to 45 Go files and `internal/manualinventory` core to
  14 Go files, with docs-check now enforcing the v0.7.5 source-count ceiling.
- Split macOS/Linux/Windows manual app scanners into
  `internal/manualinventory/platform`, keeping portable scanner evidence under
  an owning package instead of the manual inventory core.
- Extracted inventory collection/cache/sort behavior into `internal/inventoryrun`
  so command handlers only adapt config and routes.
- Moved support report construction and text rendering into `internal/support`,
  keeping command code focused on CLI parsing and TUI row adaptation.
- Moved Homebrew advisory package mapping and posture review counting into
  `internal/brew`, keeping provider metadata interpretation with the provider
  owner.
- Added shared `reviewui` state-cache helpers and routed list/update browsers
  through them for common route/focus state handling.
- Preserved the provider execution boundary: Homebrew/mise update, scan, and
  audit logs still stream through `runner`; Bubble Tea `ExecProcess` remains a
  future foreground TUI action mechanism, not the provider execution path.
