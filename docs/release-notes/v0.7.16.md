# updev v0.7.16

`updev v0.7.16` completes the Brewfile hook ownership split for the
macOS/Homebrew/mise public preview.

Highlights:

- `updev apply brewfile` reviews missing Homebrew desired-state entries and
  applies only gate-approved safe candidates with item-scoped `brew tap`,
  `brew install`, or `brew install --cask` commands.
- `updev apply brewfile --dry-run --format json` exposes every candidate,
  decision, command argv, gate reason, remediation, and evidence for automation.
- `updev list` rows for missing Homebrew desired items now include a focused
  apply-candidate route instead of sending users to a generic list.
- The daily Brewfile onchange hook remains warning-only. It checks the rendered
  Brewfile, runs `brewtmplcheck --lenient` when available, and points to updev
  review/apply commands without running `brew bundle`.
- The explicit bootstrap path remains separate: first-time setup tasks may run
  `brew bundle --file "$HOME/Brewfile"` only after warning that this bypasses
  updev safety gates.
- `[chezmoi_hooks.brewfile].mode` is parsed with `off`, `warn`, and
  `apply-safe` as the documented shape. The default daily behavior remains
  `warn`.

Validation:

- `mise -C tools/updev run check`
- `mise -C tools/updev run docs-check`
- `mise -C tools/updev run goreleaser-check`
- `mise -C tools/updev run goreleaser-snapshot`

- `updev apply brewfile --dry-run --format json`
