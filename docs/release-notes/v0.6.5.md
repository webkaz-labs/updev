# updev v0.6.5

`updev v0.6.5` is the full-scope `v0.6.x` consolidation release for the public
preview line.

## Highlights

- Adds embedded agent guidance entry points: `updev skill`, `updev skill
  --full`, and `updev help agent` print the canonical `docs/agent/` guidance
  from the released binary.
- Adds a provider compatibility ledger to `updev doctor dependencies` JSON
  output and optional `--ledger <file>` export, so local/CI contract drift can
  be recorded without public issue posting by default.
- Extends manual inventory groundwork with experimental read-only fixture
  evidence for Linux `.desktop`, Flatpak, Snap, AppImage sources, and Windows
  `winget export` JSON.
- Keeps portable manual-app and agent enrichment metadata structured: portable
  identifiers such as `desktop_id`, `package_id`, and `app_id` are searchable,
  reviewable, and preserved in draft matching.
- Keeps the existing macOS/Homebrew/mise provider-gate contract stable while
  documenting which Linux/Windows paths remain experimental before v1
  narrowing.

## Supported Scope

macOS/Homebrew/mise remains the supported preview path. Linux and Windows
binaries continue to be published, and this release includes fixture-backed
read-only evidence for early provider work, but Linux/Windows provider support
is still experimental until real runner or machine dogfood proves it.

## Upgrade Notes

No config migration is required.

- Existing `v0.6.x` config, cache, reports, and security policy files remain
  compatible.
- `updev doctor dependencies --format json` now includes
  `compatibility_ledger`.
- `updev doctor dependencies --ledger <file>` writes the same compatibility
  ledger to a local JSON file.
- `updev skill` and `updev help agent` are read-only documentation commands.
- Linux/Windows manual inventory evidence is read-only and experimental.
